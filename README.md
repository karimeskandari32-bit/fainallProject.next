# 🎓 پلتفرم دوره‌های آنلاین (Fainall)

یک وب‌اپلیکیشن فروش و مدیریت دوره‌های آموزشی آنلاین که با **Next.js** ساخته شده است. شامل ورود با پیامک (OTP)، سبد خرید، صفحه دوره‌ها و فصل‌ها، بخش نظرات، مشاور هوشمند دوره با هوش مصنوعی، و پنل مدیریت کامل (داشبورد آماری، دسته‌بندی‌ها و کدهای تخفیف) با طراحی ریسپانسیو.

🔗 **دمو زنده:** [fainall-project-next.vercel.app](https://fainall-project-next.vercel.app/)

---

## ✨ امکانات

### 🛍 بخش کاربران

- ورود و ثبت‌نام با **کد یک‌بارمصرف پیامکی (OTP)** از طریق پنل فراز اس‌ام‌اس
- لیست دوره‌ها و صفحه جزئیات هر دوره (سرفصل‌ها و جلسات)
- **مشاور هوشمند دوره (هوش مصنوعی):** کاربر هدفش را می‌نویسد و سیستم از بین دوره‌های موجود در دیتابیس، مناسب‌ترین‌ها را پیشنهاد می‌دهد
- سبد خرید
- ثبت و نمایش نظرات کاربران
- پشتیبانی از **حالت تاریک و روشن**
- طراحی ریسپانسیو برای موبایل، تبلت و دسکتاپ

### 🧑‍💼 پنل مدیریت

- **داشبورد آماری** با نمودار ثبت‌نام کاربران، تعداد سفارش‌ها و فروش ماهانه
- **تقویم شمسی:** ماه‌ها و تاریخ‌ها در نمودارها و جدول‌ها به تاریخ ایران نمایش داده می‌شوند و داده‌ها بر اساس ماه شمسی گروه‌بندی می‌شوند
- **مدیریت دسته‌بندی‌ها:** افزودن، ویرایش و حذف، با ساخت خودکار اسلاگ
- **مدیریت کدهای تخفیف:** تخفیف درصدی یا مبلغ ثابت، سقف تعداد استفاده، تاریخ انقضا، اختصاص به یک دوره، و فعال/غیرفعال‌سازی سریع
- محافظت از APIهای مدیریتی با **JWT و نقش ادمین**
- سایدبار ریسپانسیو (ثابت در دسکتاپ، منوی کشویی در موبایل)

## 🚀 اجرای پروژه روی سیستم خودتان

۱. کلون کردن پروژه:

```bash
git clone https://github.com/karimeskandari32-bit/<نام-ریپازیتوری>.git
cd <نام-ریپازیتوری>
```

۲. نصب وابستگی‌ها:

```bash
npm install
```

۳. ساخت فایل متغیرهای محیطی (بخش بعدی را ببینید)

۴. اجرای پروژه در حالت توسعه:

```bash
npm run dev
```

حالا پروژه روی [http://localhost:3000](http://localhost:3000) در دسترس است.

## ⚙️ متغیرهای محیطی

یک فایل `.env.local` در ریشه پروژه بسازید:

```env
MONGO_URI=آدرس_اتصال_به_MongoDB
ACCESS_TOKEN_SECRET=یک_رشته_تصادفی_طولانی
OPENROUTER_API_KEY=کلید_OpenRouter
```

برای بخش پیامک هم کلید و تنظیمات پنل فراز را اضافه کنید.

> فایل `.env.local` را هرگز در گیت‌هاب commit نکنید.

## 🤖 درباره مشاور هوشمند دوره

مشاور هوشمند از مدل‌های رایگان OpenRouter استفاده می‌کند. سرور فهرست دوره‌های منتشرشده را از MongoDB می‌خواند، همراه با نیاز کاربر به مدل می‌دهد و فقط شناسه دوره‌های مناسب را می‌گیرد. شناسه‌ها قبل از نمایش با دیتابیس تطبیق داده می‌شوند، پس مدل نمی‌تواند دوره‌ی ساختگی پیشنهاد دهد. اگر یک مدل شلوغ باشد، به‌صورت خودکار مدل بعدی امتحان می‌شود.

## 🔐 نکته درباره ورود در نسخه دمو

برای جلوگیری از مصرف اعتبار پیامک هنگام نمایش پروژه، در نسخه دمو یک **شماره و کد ثابت** برای ورود در نظر گرفته شده است. کد ارسال واقعی پیامک در پروژه به‌صورت کامنت نگه داشته شده و برای استفاده واقعی کافی است آن را فعال کنید.

## 📁 ساختار کلی پروژه

```
├── app/          صفحات و مسیرهای API (App Router)
├── components/   کامپوننت‌های قابل استفاده مجدد
├── models/       مدل‌های Mongoose (کاربر، دوره، سفارش، دسته‌بندی، تخفیف)
├── lib/          توابع کمکی (تاریخ شمسی، آمار داشبورد، اعتبارسنجی)
├── configs/      تنظیمات و اتصال به دیتابیس
├── store/        تنظیمات Redux
├── public/       فایل‌های استاتیک
└── ...
```
