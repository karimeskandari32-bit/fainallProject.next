# 🎓 پلتفرم دوره‌های آنلاین (Fainall)

یک وب‌اپلیکیشن فروش و مدیریت دوره‌های آموزشی آنلاین که با **Next.js** ساخته شده است. شامل ورود با پیامک (OTP)، سبد خرید، صفحه دوره‌ها و فصل‌ها، بخش نظرات، و پنل مدیریت با طراحی ریسپانسیو.

🔗 **دمو زنده:** [fainall-project-next.vercel.app](https://fainall-project-next.vercel.app/)

---

## ✨ امکانات

- ورود و ثبت‌نام با **کد یک‌بارمصرف پیامکی (OTP)** از طریق پنل فراز اس‌ام‌اس
- لیست دوره‌ها و صفحه جزئیات هر دوره (سرفصل‌ها و جلسات)
- سبد خرید
- ثبت و نمایش نظرات کاربران
- پنل مدیریت (ادمین) با **سایدبار ریسپانسیو** (ثابت در دسکتاپ، منوی کشویی در موبایل)
- پشتیبانی از **حالت تاریک و روشن**
- طراحی ریسپانسیو برای موبایل، تبلت و دسکتاپ

## 🛠 تکنولوژی‌ها

| بخش | ابزار |
| --- | --- |
| فریم‌ورک | Next.js، React |
| زبان | TypeScript |
| استایل | Tailwind CSS v4، shadcn/ui، CSS Modules |
| تم | next-themes |
| مدیریت state | Redux |
| دیتابیس | MongoDB |
| سرویس پیامک | Faraz SMS |
| دیپلوی | Vercel |

## 🚀 اجرای پروژه روی سیستم خودتان

۱. کلون کردن پروژه:

```bash
git clone https://github.com/karimeskandari32-bit/<نام-ریپازیتوری>.git
cd <نام-ریپازیتوری>
```

۲. نصب وابستگی‌ها:

```bash
npm install
```

۳. اجرای پروژه در حالت توسعه:

```bash
npm run dev
```

حالا پروژه روی [http://localhost:3000](http://localhost:3000) در دسترس است.

## 📦 ساخت نسخه نهایی

```bash
npm run build
npm start
```

## 🔐 نکته درباره ورود در نسخه دمو

برای جلوگیری از مصرف اعتبار پیامک هنگام نمایش پروژه، در نسخه دمو یک **شماره و کد ثابت** برای ورود در نظر گرفته شده است. کد ارسال واقعی پیامک در پروژه به‌صورت کامنت نگه داشته شده و برای استفاده واقعی کافی است آن را فعال کنید.

## 📁 ساختار کلی پروژه

```
├── app/          صفحات و مسیرهای API (App Router)
├── components/   کامپوننت‌های قابل استفاده مجدد
├── store/        تنظیمات Redux
├── public/       فایل‌های استاتیک
└── ...
```
